# 需求文档

## 1. 应用概述

**应用名称**：龙王社区

**应用描述**：一个移动端社区应用，用户可在不同板块发布图文帖子、视频内容，评论、点赞、关注其他用户，通过签到和完成任务获得积分，在积分商城兑换商品。支持身份证实名认证和蓝V认证申请。提供视频刷流页面和整合搜索功能。支持消息通知、举报反馈、勋章成就、用户等级、内容编辑删除、草稿箱、视频下载、黑名单、话题标签、分享统计等功能。新增智能推荐算法、内容智能分发、数据分析看板、用户行为路径分析、内容质量评分系统、编辑推荐机制、用户分组与定向运营、内容审核分级机制、批量内容操作工具、用户生命周期管理、社区标签管理系统、外部内容导入工具、用户反馈闭环管理、内容智能分类、热门内容自动聚合、用户活跃度排行榜、内容合集功能、积分任务体系、签到补签机制、热门内容自动周报、内容失效检测与提醒、文章阅读进度保存、图片批量上传与进度显示、视频倍速播放、@提及功能、一键表情回复、个人主题色自定义等功能。管理员可通过后台管理板块、用户、广告、任务、商城、视频审核、身份认证、蓝V认证、举报处理等内容，并可一键开启/关闭社区服务。

## 2. 用户与使用场景

**目标用户**：
- 普通用户：浏览帖子和视频、发布图文和视频内容、参与讨论、关注其他用户、签到、完成任务、兑换商品、申请身份认证和蓝V认证、接收消息通知、举报违规内容、获得勋章成就、提升用户等级、编辑删除内容、使用草稿箱、下载视频、管理黑名单、添加话题标签、分享内容、使用@提及功能、发送表情回复、自定义主题色、查看阅读进度、批量上传图片、调节视频倍速
- 管理员：管理板块、用户、广告、任务、积分商城、审核视频、审核身份认证和蓝V认证申请、处理举报、控制社区服务开关、查看数据分析看板、分析用户行为路径、管理内容质量评分、设置编辑推荐、进行用户分组与定向运营、配置内容审核分级、使用批量内容操作工具、管理用户生命周期、管理社区标签、导入外部内容、处理用户反馈、查看热门内容聚合、查看用户活跃度排行榜、管理内容合集、配置积分任务体系、设置签到补签规则、查看热门内容周报、检测内容失效

**核心使用场景**：
- 用户注册登录后，浏览不同板块的帖子和视频，发布图文或视频内容，与其他用户互动
- 用户搜索并关注其他用户，查看用户主页，观看其发布的内容
- 用户在视频刷流页面切换不同Tab（推荐、关注、同城等），全屏竖向滑动观看视频，点赞、收藏、评论、分享
- 用户每日签到获得积分，完成任务获得积分，使用积分兑换商品
- 用户完成身份证实名认证后，可申请蓝V认证，通过后在个人主页头像、帖子、评论、视频中显示蓝V标识
- 用户接收点赞、评论、关注、系统审核等消息通知，查看并标记已读
- 用户举报违规内容，管理员处理并反馈结果
- 用户通过签到、发帖、互动等行为获得勋章成就，提升用户等级
- 用户编辑或删除自己发布的帖子和视频，使用草稿箱保存未完成内容
- 用户下载视频，管理黑名单，添加话题标签，分享内容到不同渠道
- 用户在评论或帖子中使用@符号提及其他用户，被提及者收到通知
- 用户在评论区一键发送常用表情包，快速表达态度
- 用户在设置中自由切换主题色（暗黑/明亮/多彩），个性化界面风格
- 用户关闭文章页面后，再次打开时自动跳转到上次阅读位置
- 用户发布帖子时一次性选择多张图片，实时查看上传进度
- 用户在视频播放时自由调节播放速度（0.5x、1.0x、1.5x、2.0x）
- 管理员通过后台管理系统维护社区内容、审核视频、审核任务、兑换申请、身份认证、蓝V认证申请、处理举报
- 管理员查看数据分析看板，分析用户行为路径，管理内容质量评分，设置编辑推荐，进行用户分组与定向运营
- 管理员配置内容审核分级，使用批量内容操作工具，管理用户生命周期，管理社区标签，导入外部内容
- 管理员处理用户反馈，查看热门内容聚合，查看用户活跃度排行榜，管理内容合集，配置积分任务体系
- 管理员设置签到补签规则，查看热门内容周报，检测内容失效
- 管理员在紧急情况下一键停用社区服务，普通用户访问时显示维护页面

- 提供选择封面功能：从视频帧中截取或上传图片
- 用户填写视频标题和简介
- 添加话题标签（可选）

- 最新Tab：展示最新发布的视频
- 全屏竖向滑动切换视频

- 支持视频倍速播放，用户可自由调节播放速度（0.5x、1.0x、1.5x、2.0x）

- 页面右上角或底部悬浮按钮显示「上传视频」入口，点击后进入发布视频页

  - 应用Tab：显示匹配应用（原有应用分享功能），显示搜索结果数量统计

## 4. 业务规则与逻辑

### 4.1 注册与登录
- 注册时，用户输入邮箱后点击「发送验证码」，系统向该邮箱发送验证码
- 验证码有效期为5分钟
- 用户输入验证码、密码完成注册
- 注册成功后自动分配默认龙王号（格式：lw_+随机数字）
- 登录时，用户输入邮箱和密码，验证通过后登录成功
- 登录页面提供「记住我」勾选框，勾选后登录会话有效期为30天，不勾选时为默认时长
- 30天到期后自动退出，重新跳转登录页
- 当登录邮箱为hlcsnbb@foxmail.com且密码为ooiiuuyyttrrff55时，登录后进入后台管理系统
- 其他账号登录后进入前台页面

### 4.2 龙王号系统
- 每个用户注册时自动分配默认龙王号（格式：lw_+随机数字）
- 用户可在个人设置页修改龙王号
- 每周最多修改2次，超过次数提示「本周修改次数已用完」
- 修改时检查龙王号是否重复，重复则提示「该龙王号已被使用，请更换」
- 龙王号显示在用户主页（自己和他人）、搜索结果、帖子、评论、视频中

### 4.3 身份认证流程
- 用户在个人主页点击「身份认证」入口，进入身份认证页面
- 用户输入真实姓名、身份证号，点击「提交认证」
- 认证申请进入待审核状态
- 管理员在后台「蓝V审核管理」页面查看身份认证申请，手动点击通过或拒绝
- 审核通过后，用户完成实名认证
- 实名认证完成后，身份认证页面显示「去申请蓝V认证」的入口按钮/卡片，引导用户进一步申请蓝V认证
- 审核拒绝时，管理员可填写拒绝理由，用户可重新提交

### 4.4 蓝V认证流程
- 用户必须先完成身份证实名认证，才能申请蓝V认证
- 管理员在后台「蓝V审核管理」页面开启全局蓝V申请功能后，已完成实名认证的用户在个人主页可看到「申请蓝V认证」入口
- 用户点击「申请蓝V认证」，进入蓝V认证申请页面
- 用户输入自定义认证名称（如「官方创作者」「知名博主」等）和申请理由，点击「提交申请」
- 蓝V认证申请进入待审核状态
- 管理员在后台「蓝V审核管理」页面查看蓝V认证申请，选择通过或拒绝
- 审核通过后，用户获得蓝V认证，个人主页头像上显示蓝色勾选标记，昵称旁显示蓝V徽章和自定义认证名称
- 审核拒绝时，管理员可填写拒绝理由，用户可重新提交
- 蓝V认证通过的用户，在发帖、评论、视频中昵称旁也显示蓝V徽章

### 4.5 用户关注系统
- 用户在整合搜索页的用户Tab中搜索其他用户（按昵称或龙王号搜索）
- 点击搜索结果中的用户进入用户主页（他人）
- 用户主页（他人）展示：头像、昵称、龙王号、蓝V徽章、粉丝数、关注数、发布的帖子列表和视频列表
- 用户可点击「关注」按钮关注该用户，再次点击「取消关注」按钮取消关注
- 关注后，该用户的粉丝数+1，当前用户的关注数+1
- 取消关注后，该用户的粉丝数-1，当前用户的关注数-1

### 4.6 板块权限
- 管理员在后台为每个板块设置发布权限
- 用户在板块详情页点击「发布帖子」时，系统检查该用户是否有权限在该板块发布内容
- 无权限用户无法发布帖子

### 4.7 帖子发布与展示
- 用户发布帖子时，选择目标板块，输入标题、正文，可批量上传图片，可添加话题标签
- 图片批量上传时，实时显示上传进度
- 帖子发布后，在对应板块详情页和首页帖子列表中展示
- 帖子按发布时间倒序排列（最新帖子在前）
- 若作者已通过蓝V认证，昵称旁显示蓝V徽章

### 4.8 视频发布与审核
- 用户在发布视频页上传视频文件（mp4格式），视频上传至Supabase Storage的videos bucket
- 上传完成后进入视频剪辑页，用户进行时间轴裁剪、删除片段、选择封面、填写标题和简介，可添加话题标签
- 点击「发布」提交视频，视频进入管理员审核队列
- 管理员在后台「视频管理」页面查看待审核视频，可在线预览视频
- 管理员选择通过或拒绝审核，拒绝时可填写拒绝理由
- 审核通过后，视频对外可见，在视频刷流页、整合搜索页、用户主页中展示

### 4.9 视频刷流与多Tab功能
- 用户在视频刷流页可切换不同Tab：推荐、关注、同城、热门、最新
- 推荐Tab：展示系统推荐的视频
- 关注Tab：展示用户关注的其他用户发布的视频
- 同城Tab：获取用户浏览器位置（经纬度），展示同城用户发布的视频，按距离或发布时间排序

## 6. 验收标准

1. 用户访问首页，查看广告轮播和板块列表
2. 用户点击「注册」，输入邮箱，点击「发送验证码」，收到验证码邮件
3. 用户输入验证码和密码，完成注册，自动分配默认龙王号
4. 用户使用邮箱和密码登录，勾选「记住我」，登录成功
5. 用户在个人主页点击「身份认证」，输入真实姓名和身份证号，提交认证
6. 管理员登录后台（使用hlcsnbb@foxmail.com和ooiiuuyyttrrff55），在「蓝V审核管理」页面审核身份认证申请，通过审核
7. 用户在身份认证页面看到「去申请蓝V认证」入口，点击进入蓝V认证申请页面
8. 用户输入自定义认证名称和申请理由，提交申请
9. 管理员在后台审核蓝V认证申请，通过审核
10. 用户个人主页头像上显示蓝色勾选标记，昵称旁显示蓝V徽章和自定义认证名称
11. 用户在视频刷流页切换不同Tab（推荐、关注、同城、热门、最新），全屏竖向滑动观看视频
12. 用户点击右上角或底部悬浮按钮「上传视频」，上传视频，进入视频剪辑页，进行时间轴裁剪、选择封面、填写标题和简介，添加话题标签，点击「发布」
13. 管理员在后台「视频管理」页面审核视频，通过审核
14. 用户在视频刷流页调节视频播放速度（0.5x、1.0x、1.5x、2.0x），点击「下载」按钮，下载视频到本地
15. 用户在帖子详情页点击「举报」按钮，选择举报类型，输入举报理由，提交举报
16. 管理员在后台「举报处理」页面查看举报，选择删除内容，处理后向举报者发送处理结果通知
17. 用户在消息通知页查看点赞、评论、关注、系统审核、@提及等通知，点击消息标记为已读
18. 用户在勋章成就页查看获得的勋章列表
19. 用户在发布帖子页点击「保存草稿」，保存未完成内容到草稿箱，在草稿箱页继续编辑
20. 用户在用户主页（他人）点击「拉黑」按钮，将该用户加入黑名单，在黑名单管理页查看已拉黑的用户列表
21. 用户在帖子详情页点击话题标签，进入话题聚合页，查看该话题下的帖子和视频列表
22. 用户在帖子详情页点击「分享」按钮，选择分享渠道（微信/QQ/微博/复制链接），系统记录分享行为
23. 管理员在后台「分享统计」页面查看所有内容的分享统计
24. 管理员在后台「紧急停用开关」页面开启紧急停用功能
25. 普通用户访问前端时显示维护页面，点击「管理员登录」按钮，输入管理员账号密码，进入后台管理系统
26. 用户在发布帖子页一次性选择多张图片，实时查看上传进度
27. 用户在评论区使用@符号提及其他用户，被提及者收到通知
28. 用户在评论区一键发送常用表情包
29. 用户在主题色设置页选择主题色（暗黑/明亮/多彩），立即应用到界面风格
30. 用户在帖子详情页阅读后关闭页面，再次打开时自动跳转到上次阅读位置
31. 用户在签到页面点击「补签」按钮，补签过去7天内的漏签日期
32. 管理员在后台「数据分析看板」页面查看社区核心数据指标和趋势图表
33. 管理员在后台「用户行为路径分析」页面查看用户行为路径图
34. 管理员在后台「内容质量评分管理」页面手动调整内容质量评分
35. 管理员在后台「编辑推荐管理」页面添加内容到编辑推荐列表
36. 管理员在后台「用户分组与定向运营」页面创建用户分组，对特定用户分组进行定向运营
37. 管理员在后台「批量内容操作工具」页面批量选择内容进行操作（删除、隐藏、推荐、置顶）
38. 管理员在后台「外部内容导入工具」页面导入外部内容（如CSV文件、API接口）
39. 管理员在后台「用户反馈闭环管理」页面查看用户反馈列表，选择处理方式，处理后向反馈者发送处理结果通知
40. 管理员在后台「热门内容自动周报」页面查看热门内容周报
